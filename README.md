# 项目名称

大学英语welearn平台自动刷题脚本「练习流程辅助，供个人学习研究」

## 功能

开启自动刷题之后，脚本自动检索未完成的练习并进入练习完成做题工作

自动提交，从点击开始到全部题目做完一站式完成，降低人工干预

## 文件说明

| `Automation-Script_welearn.js` | 主脚本 |

## 使用方法

1. 安装 浏览器篡改猴插件，URL：https://www.tampermonkey.net/
2. 浏览器扩展设置中启用篡改猴 允许用户脚本 添加站点访问权限
3. 将本项目的脚本文件导入油猴
4. 进入welearn网页，在工具窗中配置模型api_key，开始自动刷题
